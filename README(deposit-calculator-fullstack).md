# Калькулятор вклада Neoflex (Fullstack)
Проект представляет собой калькулятор вкладов с ежемесячной капитализацией процентов (сложный процент).
## 🚀 Чек-лист для запуска приложения после открытия IDEA
Чтобы запустить и протестировать приложение, необходимо поднять два сервера: бэкенд и фронтенд.

### Шаг 1. Запуск бэкенда (Java / Spring Boot)
1. запустить `DepositCalculatorApplication.java`.
2. Бэкенд запустится и начнет слушать порт **`8080`**.

### Шаг 2. Запуск фронтенда (React / TypeScript / Vite)
1. В терминале перейдите в папку фронтенд-модуля с помощью команды:
   ```bash
   cd deposit-calc-ui
   ```
3. Запустите локальный сервер разработки Vite командой:
   ```bash
   npm run dev
   ```
4. В терминале появится ссылка.
   **`http://localhost:5173/`**

---

## 🛠️ Стек технологий проекта

* **Backend:** Java 17+, Spring Boot 3, Spring Web, Lombok, Jakarta Validation (Hibernate Validator).
* **Frontend:** React, TypeScript, Vite, Axios (сетевой слой).
